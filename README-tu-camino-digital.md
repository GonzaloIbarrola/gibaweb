# Tu Camino Digital

Sitio web desarrollado en WordPress para Tu Camino Digital, una marca personal orientada al diseno digital, branding y plantillas editables para redes sociales. La propuesta comunica servicios, portfolio, experiencia profesional y canales de contacto con una estetica enfocada en emprendedoras y marcas que buscan mejorar su presencia visual.

<!-- portfolio:start -->
Tu Camino Digital es un sitio institucional y comercial construido sobre WordPress para presentar servicios de diseno para redes sociales, packs de plantillas editables en Canva, portfolio de recursos digitales y experiencia profesional de la marca.

El proyecto prioriza una navegacion clara entre secciones, mensajes comerciales directos y contenido optimizado para convertir visitas en consultas, manteniendo una identidad visual cercana, creativa y alineada con el universo Canva.

## Features

- Sitio institucional desarrollado en WordPress.
- Secciones para inicio, sobre mi, portfolio y servicios.
- Comunicacion orientada a diseno digital, branding y redes sociales.
- Presentacion de packs comerciales para Instagram.
- Integracion con enlaces externos a Canva, Pinterest, CapCut, TikTok e Instagram.
- Imagen de proyecto preparada para el portfolio en `/images/projects/tu-camino-digital/cover.png`.

## Challenges

El desafio principal fue convertir una marca personal con multiples puntos fuertes en una experiencia ordenada: servicios, trayectoria, portfolio, beneficios y llamados a la accion debian convivir sin competir entre si. La estructura del sitio ayuda a que el usuario entienda rapidamente que ofrece la marca y pueda avanzar hacia una consulta o hacia el portfolio externo de Canva.
